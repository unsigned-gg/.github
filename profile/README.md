# unsigned

**The engine. Open, forkable GPU and orchestration stack.**

Priced like plumbing, with no vendor lock-in by design.

[unsigned.gg](https://unsigned.gg) · Part of [Vesperan](https://vesperan.com)

---

### The Doctrine

> "Build what we would rent."

Compute is encrypted in use, scheduling is deterministic, and orchestration is open. If a company built on our stack wants to leave with everything it owns — weights, corpus, audit trail — it can, any day.

---

### Core Foundations

- **[uas](https://github.com/unsigned-gg/uas)**: Unsigned Agent Substrate — Rust-native pooled harness runtime with zero-I/O domain layering.
- **[unsigned-paas](https://github.com/unsigned-gg/unsigned-paas)**: Bare-metal Talos & Kubernetes infrastructure for AI/ML execution.
- **[substrate](https://github.com/unsigned-gg/substrate)**: Core agent substrate and execution primitives.
- **[herdr](https://github.com/unsigned-gg/herdr)**: The runtime your coding agents live on — multiplexed session control without tmux.
- **[omp](https://github.com/unsigned-gg/omp)**: AI coding agent for the terminal with hash-anchored edits, optimized tool harness, and LSP integration.
- **[escapement](https://github.com/unsigned-gg/escapement)**: Metered, deterministic dispatch engine for autonomous agent swarms.
- **[reach](https://github.com/unsigned-gg/reach)**: AI-drivable containerized desktop sandbox.
- **[ax](https://github.com/unsigned-gg/ax)**: Open agentic orchestration runtime.
